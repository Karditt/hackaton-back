# Сервис планирования и распределения беспилотных авиационных работ

Решение кейса ГК «Геоскан». Сервис делит площадную аэрофотосъёмку большой
области между разнотипными беспилотниками (самолёты и коптеры):

- **Вход** — файлы из ГИС: область съёмки, запретные зоны с высотами и временем
  действия, высотные препятствия, площадки взлёта-посадки (KML), параметры
  задания (JSON): тип съёмки и разрешение (GSD), пул техники, коридор высот,
  ветер, сроки. Площадок нет — места подбирает сервис.
- **Выход** — полётное задание каждого борта и общее расписание (KML для
  Google Earth, GeoJSON, CSV, архив) **или** отчёт «невыполнимо» с причиной и
  советом, проверенным расчётом. Частичных планов нет.
- **Безопасность** — каждый план проходит независимый краш-тест: запретные зоны
  по высоте и времени, препятствия, разведение бортов в 4D, заряд, коридор
  высот. Нарушение — не предупреждение, а отказ.
- **Оптимизация** — два режима: минимум срока или минимум ресурса техники (в
  том числе к сроку). Против равномерного деления работы: срок **−28…−77%**,
  ресурс **−36…−81%**, в том числе на данных заказчика.
- **Вопросы руководителя** — «сколько бортов нужно к сроку», «срок при N
  бортах», «срок или ресурс», «где поставить ещё площадку»; каждый ответ —
  полный план с краш-тестом.

## Запуск

Нужен Docker (Docker Desktop на Windows и macOS).

```bash
git clone <ссылка на репозиторий>
cd hackaton-back
docker compose up --build
```

Первая сборка — несколько минут. Затем:

- **интерфейс** — <http://localhost:5173>
- **API** с интерактивным описанием (OpenAPI) — <http://localhost:8000/docs>

Тестовые сценарии и данные заказчика подгружаются сами.

**Без Docker** (Python 3.11+, Node.js 20+):

```bash
pip install -e ".[dev]"
uvicorn api.main:app --port 8000          # API
cd web && npm ci && npm run dev           # интерфейс, в другом окне
```

Ядро работает и без интерфейса — из командной строки:

```bash
python -m core.cli scenarios/demo_100km2.json -o out/   # план и файлы в out/
pytest                                                  # автотесты
```

## Что посмотреть за 5 минут

1. Сценарий **«Демонстрационный: ~95 км², 10 бортов»** → «Рассчитать» (около
   минуты): итог, маршруты на карте, вкладка «Расписание», «Сравнение с
   равномерным делением», выгрузка заданий бортов.
2. **«Невыполнимый»** → «Рассчитать»: отчёт о невыполнимости с причиной и
   советом, проверенным расчётом.
3. **«Московская область: 245 км², 549 участков»** — настоящие данные заказчика
   (расчёт около 5 минут).
4. **«+ Новый сценарий из своих файлов»** под списком сценариев — свои KML: область
   обязательно, зоны, препятствия, площадки и параметры по желанию. Образцы
   формата — `scenarios/sources/` и ссылки на исходные файлы любого сценария в
   панели «Данные и слои» на карте.
5. Панели **«Подсказка по флоту»**, **«Срок или ресурс»**, **«Где поставить ещё
   площадку»** и вкладка **«Техника»** (ТТХ бортов с источниками).

## Структура репозитория

```
core/          ядро: вся логика расчёта, чистый Python, своя командная строка
  geo/           проекции, геометрия, зоны, препятствия, импорт KML
  survey/        GSD → высота, шаг галсов, скорость при ветре
  coverage/      подобласти, галсы, зоны манёвра
  flight/        фазы полёта, развороты, расход заряда
  transit/       обход зон и препятствий (граф видимости)
  allocate/      распределение: baseline, эвристика, локальный поиск
  deconflict/    эшелоны, расписание, разведение бортов
  validate/      краш-тест готового плана
  advise/        причины невыполнимости и советы
  export/        KML, GeoJSON, CSV, задания бортов
  schemas.py     контракт данных
  assumptions.py все константы и допущения с источниками
api/           REST API (FastAPI): приём сценариев, фоновый расчёт, выгрузка
web/           интерфейс (React + TypeScript + Leaflet)
data/          каталог БВС с источником у каждого числа, перекрытия, образцы данных заказчика
scenarios/     тестовые и демо-сценарии; sources/ — они же слоями KML и параметрами
tests/         автотесты, в том числе краш-тест на испорченных планах
docs/          документация; sources/ — документы производителя и ТЗ;
               dev/ — рабочие документы команды (для проверки не нужны)
docker-compose.yml  запуск одной командой
```

## Стек и данные

Python 3.11 (shapely, pyproj, numpy, pydantic, FastAPI), React + TypeScript +
Vite + Leaflet, Docker. Внешних сервисов, ключей и платных лицензий нет.
Подложка карты — © OpenStreetMap contributors (ODbL). ТТХ бортов Геоскан (201,
201 Термо, Lite, 401 Геодезия, 801, Gemini) — из официальных документов
производителя (`docs/sources/`) с источником у каждого параметра в
`data/vehicles.yaml`.
