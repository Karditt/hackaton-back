# CLAUDE.md

Сервис планирования и распределения беспилотных авиационных работ: по сценарию (область съёмки, тип съёмки, флот БВС, площадки взлёта, запретные зоны, ветер) рассчитываются полётные задания для группы разнотипных БВС и выгружаются в KML/GeoJSON. Оптимизация по двум критериям: makespan и суммарный налёт.

## Правило сессии

**Начинать с чтения [`docs/current_state.md`](docs/current_state.md), заканчивать его обновлением.**

Полные правила разработки — в [`AGENT.md`](AGENT.md). Прочитать перед первой правкой кода.

## Команды

> Целевые команды. Код ещё не написан — они появляются в рамках E0 (каркас). Фактическое состояние — в `docs/current_state.md`.

```bash
# запуск всего (api + web) на чистой машине
docker compose up

# ядро без веба
pip install -e ".[dev]"
python -m core.cli scenarios/simple.json -o out/mission.geojson

# тесты
pytest

# прогон на всех тестовых сценариях
python -m core.cli --batch scenarios/ -o out/

# генерация TypeScript-типов из core/schemas.py (после ЛЮБОЙ правки контракта)
python -m core.cli export-schema -o web/src/types/schema.json
cd web && npm run gen:types   # закреплённая версия генератора из web/package.json
```

## Критичные инварианты

1. **Вся геометрия — в метрической проекции.** WGS84 только на границах: вход сценария и выход экспорта. Ошибка от расчётов в градусах — тихая.
2. **`core` не импортирует `api` и `web`.** Ядро запускается как `python -m core.cli` и живёт без веба.
3. **`core/schemas.py` — общий контракт.** Правка только осознанно, с отметкой в `current_state.md` и перегенерацией TS-типов.
4. **Ветер — метеорологическая конвенция (откуда дует).** Перепутанный знак даёт зеркальный план, видно только на демо.
5. **Физические константы — только в `core/assumptions.py`**, каждая с источником. ТТХ БВС — только из `data/vehicles.yaml`, не выдумываются.
6. **Baseline-алгоритм (равномерное деление) не удаляется никогда** — точка сравнения для доказательства эффективности.
